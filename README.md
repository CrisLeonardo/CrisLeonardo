**Highlights:**
- 🌐 Wildcard subdomains per restaurant (`brand.domain.com`)

- 🔐 Multi-role RBAC with Supabase RLS — zero cross-tenant data leaks

- 🗄️ Redis cache + idempotent SQL migrations
